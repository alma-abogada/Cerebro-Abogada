# Sistema y soporte

- **Cerebro:** este repositorio privado (`https://github.com/giovannamirena/cerebro-abogada.git`), creado por Antetodo para Alma; ella entra como colaboradora
  con permiso de escritura y se le puede transferir a su cuenta cuando lo pida. Se actualiza solo
  al abrir sesión (`git pull`) y se respalda solo al terminar cada respuesta (autoguardado). Las skills viven en `.claude/skills/`.
- **`privado/` no se respalda en GitHub.** Si cambia de computadora, esa carpeta hay que pasarla a mano.
- **Soporte:** Antetodo Marketing (antetodomarketing.com). Sus cambios llegan solos con el `git pull` al abrir sesión.
